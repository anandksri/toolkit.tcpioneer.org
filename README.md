# TCPioneer Security Toolkit

A collection of small browser-based security and utility tools built for The Cyber Pioneer.

## Tools

- Password checker
- Phishing detector
- QR generator

The project is intentionally lightweight and uses static HTML, CSS, and JavaScript for the current tools.

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Getting Started

Clone the repository:

```bash
git clone https://github.com/anandksri/toolkit.tcpioneer.org.git
cd toolkit.tcpioneer.org
```

Open `index.html` in a browser or serve the directory with any local static web server.

## Project Structure

```text
index.html                 Toolkit landing page
assets/css/                Stylesheets
assets/js/                 JavaScript
assets/images/             Shared images and assets
password-checker/          Password checking tool
phishing-detector/         Phishing detection tool
qr-generator/              QR generation tool
```

## Security Notes

These tools are intended for learning and basic utility purposes. Results should not be treated as a replacement for professional security analysis or dedicated security tooling.
